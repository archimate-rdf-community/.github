# ArchiMate RDF Community

A coordination space for people working on RDF representations of the ArchiMate® modeling language.

Several independent ArchiMate RDF efforts exist, and each has solved a different part of the problem. This space is where their authors work out how to align.

## Current status

We're agreeing on goals before anything else. Join the [kickoff discussion](../../discussions).
